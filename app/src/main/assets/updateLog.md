# 1.0.0 (2026-09-07)
- 新增阅读记录总览，支持年度热力图、周期统计、周阅读柱状图和24小时阅读分布
- 新增书籍阅读详情，展示阅读数据、阅读日历、书评等
- 新增评分总览，可按星级筛选书架书籍
- 新增书评总览，支持查看所有书籍评价
- 支持在书籍末页快速添加书评
- 优化阅读统计口径，改为按书籍URL识别并支持历史记录合并
